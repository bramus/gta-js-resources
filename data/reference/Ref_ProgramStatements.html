Name

Program Statements - List of Program Statement Keywords

Availability

all GTA Demos, GTA Full Version

Description

150 different program statement keywords determine the type of the actions in the second section of a mission in the MISSION.INI file.

There are several lists available:

Overview (below) - List of Program Statements with short descriptions (still under construction)
You can find a better, but still incomplete overview in Olivier Mengué's Mission.ini Reference.

Program Statement Index - Index of Program Statement section of the handbook, contains links to detailed Program Statement descriptions

Token list (text) - List of object and program statement keyword tokens for use with the GTA Editor Project

Program Statement statistics - big list of all Program Statements and the numbers of their occurences in MISSION.INI. Provided as examples are their first occurences in that file. Use this if you want to research unknown Program Statements.
