Cars - Car Data Table

Availability

all GTA Demos, GTA Full Version

Description

Cars and other objects can be placed on the map using the PARKED Object Code.

Legend

T = parameter for PARKED

$$$ = Mint Value at Dock

Name = Name of vehicle

sp = Speed quality

FXT = Car Name Message ID in SPECIAL.FXT (Full game)

hd = Handling Quality

nyc: x or color = available, - = not available in Liberty City Demo, crash = game crashes when car is entered

dm = Damage Quality
av = availability

sanb: like sanb, but for San Andreas Demo

ds = desirability

real name: car that exists in the real world

Usage:

No limitations reported. It seems that the game crashes when it can't find the name of the car in the active FXT file at the time the car is entered.

Helicopter:

The Helicopter can be used if a [car88]Helicopter line is added to the active FXT file. Sad to say, the Helicopter drives like a truck or bus...

Examples

293 1 (106,119,4) PARKED 31 0
Bulldog, parked facing south in front of the...
238 1 (127,92,4) PARKED 22 0
Taxi, parked facing south in front of a strip joint in North Park
511 1 (248,78,4) PARKED 41 512
Superbike, parked facing north on Law Island
The examples were taken from section [1] of MISSION.INI.
