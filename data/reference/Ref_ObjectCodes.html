Name

Object Codes Overview - List of Object Code Keywords

Availability

all GTA Demos, GTA Full Version

Description

72 different object code keywords determine the type of the objects in the first section of a mission in the MISSION.INI file.

There are several lists available:

Overview (below) - List of Object Codes with short descriptions (still under construction)
You can find a better, but still incomplete overview in Olivier Mengué's Mission.ini Reference.

Object Code Index - Index of Object code section of the handbook, contains links to detailed object code descriptions

Token list (text) - List of object and program statement keyword tokens for use with the GTA Editor Project

Object Code statistics - big HTML table of all object codes, numbers of their occurences with/without mysterious 1, number of parameters, 8/14bit coordinates. Use this if you want to research unknown object codes.
