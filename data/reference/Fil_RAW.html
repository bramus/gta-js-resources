Name

*.RAW - graphics used in pre-game screens and cutscenes

Location

gtadata\*.raw
gtados\gtadata\*.raw

Availability

all GTA Demos, GTA Full Version

Description

GTADOS\DATA\FLAG2.RAW
20x200, interleaved RGB: flags for language selection, in gray levels.
GTADOS\DATA\JOY.RAW (342 bytes)
19x18, grayscale: circle used to calibrate joystick in setup.
GTADATA\CUT[0-5].RAW (921600 bytes)
640x480, interleaved RGB: pictures at the end of each level.
GTADATA\F_BMG.RAW
100x50, interleaved RGB: BMG logo.
GTADATA\F_DMA.RAW
78x109, interleaved RGB: DMA logo.
GTADATA\F_LOGO?.RAW
640x168, interleaved RGB: the GTA logo from menus, with little variations.
GTADATA\F_LOWER0.RAW
640x312, interleaved RGB: lower part of menu background.
GTADATA\F_LOWER1.RAW
640x312, interleaved RGB: lower part of menu background, with USA states.
GTADATA\F_UPPER.RAW
640x168, interleaved RGB: upper part of menu background.
GTADATA\F_PAL.RAW (768 bytes = 256x3)
Not a bitmap. It must be the palette for the game (-> .gry files).
GTADATA\F_PLAY[1-8].RAW
102x141, interleaved RGB: Player faces.
GTADATA\F_PLAYN.RAW
180x50, interleaved RGB: Frame for player name.

Usage

You can load these Files into PaintShopPro. Header size is 0 Bytes.

Notes

Information contributed by Olivier Mengué; also available on his Format of .Raw files page
