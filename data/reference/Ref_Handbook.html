Every page in this handbook has certain standardized sub-headings that let you quickly size up the info you need. These Headings are:

Header - Name, Section, Filename. Click on the section to get the section index!

Name - Name and really short descripton

Synopsis - General appearance of it

Availability - To which versions does it pertain?

Description - long description: what does it?

Parameters - What are the possible parameters and their meaning? Refers to the Synopsis.

Usage - How is it applied?

Examples - Examples

See Also - related information

Notes - Contributors and other info

Bugs - possible clashes of reality with the info on the page

Footer - last change date
