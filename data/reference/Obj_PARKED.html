Name

PARKED - places parked cars (and other objects?) on the map.

Synopsis

### 1 (x,y,z) PARKED t d

Availability

all GTA Demos, GTA Full Version

Description

Cars and other objects can be placed on the map. The cars can be entered and used by the player.

Parameters

###

object index

1

always 1

(x,y,z)

object coordinates

t

Car/Object Type (0-106?) (see below)

d

direction of object:

0 = South
256 = East
512= North
768 = West

Any value in the range 0-1023 should be permissible for odd directions.

Use this formula for compass heading c:
c=(d-512)*90/256; add 360 if the value is negative.
d=(c-180)*256/90; add 1024 if the value is negative

Usage:

Placement:

No limitations reported. It seems that the game crashes when it can't find the name of the car in the active FXT file at the time the car is entered.

Activation:

Parked cars can be entered and driven by the player. Can a parked car be activated by a program statement? PARKED Cars often hace CARTRIGGER objects with them to start missions (or the car alarm?).

Examples

293 1 (106,119,4) PARKED 31 0
Bulldog, parked facing south in front of the...
294 1 (105,119,4) PLAYER 293 256
... player's starting position in "Gangsta Bang"
238 1 (127,92,4) PARKED 22 0
Taxi, parked facing south in front of a strip joint in North Park
239 1 (127,92,4) CARTRIGGER 2000 238
Triggers Taxi mission program at 2000 when the car is entered
511 1 (248,78,4) PARKED 41 512
Superbike, parked facing north on Law Island
The examples were taken from section [1] of MISSION.INI.
