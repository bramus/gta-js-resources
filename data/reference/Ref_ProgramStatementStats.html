Program Statement Statistics

This is absolutely every Program Statement in GTA. I am sure of that because I pulled this list out of the the full version GTADOS\GTA8.EXE. I also have an object code list. If you can provide info on what these codes mean, please do so. If you want to know what Program Statements are, look at MISSION.INI ; short descriptions and other lists are here.

Also available: 1) a text version of this table. 2) Text file with first occurences for each keyword. Both include information on program statements as well. They files have been produced using a script for the "awk" tool; I can make both available to you if you ask me about them.

This file will be updated with info on which parameters are actually used by the keywords.

Michael Mendelsohn
