フリーバージョン...

GTA1 は Rockstar Games のサイトで無料配布されています。英語版ですが、プレイしたことのない方は一度体験してみてはいかがでしょうか。Windows2000やXPでも動作するようにチューンされているそうです。(約328MB)

フリーなので基本的に何の動作保証もありません。動作したらラッキーぐらいに考えてください。

  • 4Gamer.net (ミラー) ※お薦め

オフィシャルサイトは名前やら何やらを書かなければならないので、4Gamer.net からのダウンロードをお薦めします。

エラーが表示されてゲームが起動しない

事象
「WinDirect Error / Unable to link to KERNEL32.DLL!」、「MGL Fatal Error! / Cannot load WDIRxxF.DLL!」というエラーが表示されてゲームが起動しない
対処
コマンドプロンプトから「Grand Theft Auto.exe」を直接実行する

以下、GTA を「D:\Program Files\Rockstar Games\Grand Theft Auto」にインストールしたと仮定して説明します。インストールした場所がわからない場合は、「"gta settings.exe"」(引用符込み)というファイルを検索してください。

  1. 「スタート」メニューから「ファイル名を指定して実行」を選択
  2. 「cmd」と入力し、「OK」ボタンを押下する。コマンドプロンプトが起動する
  3. GTA をインストールしたディレクトリに移動

    Microsoft Windows XP [Version 5.1.2600]
    (C) Copyright 1985-2001 Microsoft Corp.

    C:\Documents and Settings\foo> D:

    D:\> cd "\Program Files\Rockstar Games\Grand Theft Auto\WINO" ←引用符も忘れずに

    D:\Program Files\Rockstar Games\Grand Theft Auto\WINO> ←最後が「WINO」となっていること

  4. GTA を起動

    D:\Program Files\Rockstar Games\Grand Theft Auto\WINO> "grand theft auto" ←引用符も忘れずに入力

  5. ゲームが起動します

※ゲームをプレイするたびに毎回実施してください。

エラーが表示されてゲームが起動しない(その2)

事象
「MGL Fatal Error! / Please run 'Settings' first (error: open registry key)」というエラーが表示されてゲームが起動しない
対処
キー設定を先に行う
  1. スタートメニューから「GTA Settings」を起動する。（ゲームを起動するメニュー項目と同じ場所にあります）
  2. 「Grand Theft Auto Settings」が起動する。
  3. キー設定を行う。
  4. 「Save」ボタンを押下する。
  5. ゲームを起動する。

※初回起動時のみです。

妙に重い

事象
スペックは十分のはずなのに妙にゲームがカクカクする
対処
サウンドのアクセラレートレベルを下げる
  1. 「スタート」メニューから「ファイル名を指定して実行」を選択
  2. 「dxdiag」と入力し、「OK」ボタンを押下する。
  3. 「DirectX 診断ツール」が起動する。
  4. 上部にある「サウンド」タブを押下する。
  5. 「ハードウェア サウンド アクセラレータ レベル」のつまみを一つ左に動かす。
  6. ゲームを起動する

※改善されない場合は、改善されるまでつまみを一つずつずらしてみてください。一番左でもだめだった場合は、サウンドカードのドライバをアップデートしてみてください。

※他のゲームをプレイする時はつまみの位置を元に戻した方がいいです。

マップ選択後、Windows に戻ってしまう

事象
2回目以降の起動時、マップを選択したあと、Windows に戻ってしまう
対処
インストール直後の「PLAYER_A.DAT」ファイルを取っておき、ゲームを起動するたびに当該ファイルを手動で上書きする
  • これをすると、ハイスコアや、クリアしたマップの記録が保存されません。
  • 先のマップへ行きたい場合はチートを使用してください。
  • ファイルは「<GTA1のインストールディレクトリ>\GTADATA」にあります。
  • インストール直後の「PLAYER_A.DAT」がない場合、インストールし直してください。
