GTA Rockstar Classics / Steam Edition:

FIXED There is no menu music and no pause-music; Track10.wav is never played?
=> fixed by with ASI patch GtaClassicMusicFix.asi by me

FIXED Wrong music files are loaded. You hear cop sounds instead of atmo.
Renaming the WAV files is only a workaround. The actual bug is in the EXE file,
since the WAV files have the correct order.
=> fixed with an ASI patch GtaClassicMusicFix.asi by me

FIXED Resolution will not be preserved for the next session.
It will be correctly saved in player_a.dat, but the game will crash
when the resolution byte in player_a.dat (fifth byte) is not 6.
=> fixed with the widescreen ASI patch which was enhanced by me, or alternatively with the ASI patch GtaClassicPlayerAFix.asi.
=> Alternatively, use GTAFixer.exe , but then the resolution is not preserved for the next game session

FIXED The Rockstar Classics / Steam edition will corrupt player_a.dat files created by the Retail version,
because they have different file formats. Fixed with an ASI patch PlayerAConverter_Automatic.asi by me.

FIXED French Translation does not display the "œ" ligature and the ñ character. This was fixed in my language patch by replacing œ with "oe" and ñ with "n".
The same problems happens with non-implemented Kanji characters 嗅, 洒, 訛 which are displayed as "！". In my patch they have been replaced with Hiragana characters.

OPEN If sounds AND music are set of "off", you still hear horns and other traffic sounds.
But you don't hear crashes and foot steps. If music is NOT "off", then everything works as expected.

OPEN The music stops after some playtime until the game is restarted
=> A new version of mss32.dll seems to have fixed the issue, but this new version
has another big disadvantage: The music is loud and extremely noisy, especially if played with low volume.
It sounds very broken.

OPEN (small issue): If you increase the sound volume, the music volume increases too (in option screen).

OPEN 32 bit color depth: graphics flickers. 16 bit color depth: game is slow, even with frame limiter off.

OPEN GTA London for DOS: Cutscene animations are too fast and have no subtitles.

GTA Retail, London69 and London61 incompatibilities:

  • Menu animations are too fast
  • Cut scene replay is too fast and crashes
  • No sounds at menu?
  • soundtrack stutters after some gaming time
  •  32 bit color depth: graphics flickers. 16 bit color depth: game is slow, even with frame limiter off.

Bugs in GTA London 1961:

  • The game will crash if it is started with a non-English language setting.
    Reason: It is only translated to English.
    Solution: Either change the language setting, or copy the file enguke.fxt to e.g. geruke.fxt (German).

Bugs in GTA 1 (Retail and Classics):

  • The cheat "suckmyrocket" will give you 3 armor, but it does not protect you. You still die with a single shot.

Problems with the widescreen patch:

  • Menus and cut scenes are not stretched to widescreen / fullscreen
