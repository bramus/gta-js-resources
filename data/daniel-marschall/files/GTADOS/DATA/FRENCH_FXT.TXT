[IWAV.DIG]Sélectionnez ce gestionnaire si votre carte sonore fonctionne avec un processeur audio InterWave (TM). C'est le cas des cartes Core Dynamic Dynasonix, Reveal WaveExtreme 32 et de la STB SoundRage 32. Certains ordinateurs Compaq et Gateway 2000 utilisent également le processeur audio InterWave. Pour plus d'informations, consultez le fabricant.
[NVDIG.DIG]Choisissez ce gestionnaire si votre système est équipé d'un accélérateur multimédia compatible NVidia. Si le gestionnaire ne parvient pas à détecter votre carte, contactez le revendeur de votre système ou de votre carte pour obtenir une version plus récente du gestionnaire.
[RAP10.DIG]Attention: pendant la détection automatique de la carte Roland RAP-10, le gestionnaire vérifie que la carte RAP-10 est présente à l'adresse 320H ou 330H. Il ne contrôle pas le canal DMA ou les paramètres IRQ de la carte. Si votre carte RAP-10 n'est pas configurée sur l'IRQ 9 ou si les canaux DMA 5 et 6 sont déjà utilisés par une autre carte sur votre système, vous devez choisir l'option 'Ignorer l'auto-détection et configurer manuellement la carte sonore' dans le menu suivant. Il faudra ensuite entrer les paramètres de port de votre carte. Si vous n'effectuez pas ces changements, l'ordinateur risque de se bloquer et les sons irréguliers.
[PROAUDIO.DIG]Ce gestionnaire permet d'obtenir un son numérique stéréo avec toutes les versions de la carte Pro Audio Spectrum de Media Vision. Si vous avez un problème, sélectionnez le gestionnaire compatible Sound Blaster. L'utilitaire MVSOUND.SYS de Media Vision doit être chargé en mémoire, sinon votre carte ne sera pas détectée.
[ULTRA.DIG]Lorsque vous utilisez ce gestionnaire, assurez-vous que les utilitaires Gravis comme SBOS, UltraMID, ou Mega-Em ne sont pas actifs. Vous devez posséder la version 2.0, ou plus du logiciel UltraSound system.
[JAMMER.DIG]La carte WaveJammer de New Media Corporation permet d'obtenir un son de haute-qualité sur les ordinateurs portables à cartes PCMCIA. Choisissez le gestionnaire de la carte sonore Ad Lib(R) Music Synthesizer pour un son FM avec une carte WaveJammer..
[SNDSCAPE.DIG]Choisissez ce gestionnaire si vous avez une carte sonore compatible Ensoniq SoundScape(TM).
[SNDSYS.DIG]Choisissez ce gestionnaire si votre carte sonore est compatible avec le Microsoft Windows Sound System. Si le canal DMA 1 n'est pas utilisable par votre carte Windows Sound System, vous devez choisir l'option 'Ignorer l'auto-détection et configurer manuellement la carte et sélectionner un autre canal DMA. Si vous êtes sous Windows 95, utilisez l'option 'Voir configuration Windows 95' dans le menu principal, pour connaître l'adresse du système sonore de Windows.

Les cartes MPU-401 ont généralement les meilleures performances sonores, mais les utilisateurs de contrôleurs SCSI Adaptec doivent choisir l'option 'Ignorer l'auto-détection et configurer manuellement la carte sonore' dans le menu suivant, pour limiter les problèmes liés à la détection MPU-401. Si vous avez une carte Creative Labs AWE-32, choisissez l'option "Creative Labs AWE-32(TM) General MIDI".
