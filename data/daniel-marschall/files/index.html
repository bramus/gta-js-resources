Annotations:

  • misse8.ini and enge8.fxt are used in the "GTA Max" hack, to enable 8 bit mode for London 1961 (which does only support 24 bit and 3dfx modes for DOS, besides Windows of course).
    The trick was to use gta8_uk.exe (London 1969 DOS), rename it to gta8_61.exe, and change file paths inside the EXE file.
    Since the string sizes cannot change, the filenames had to change to make them fit: "uke" became "e8".
    However, this will not fully work, because the mission commands "PLAYER_DRIVE_BY" and "PLAYER_DRIVE_BY_OFF" are new in UKE and not implemented in UK!
  • To play the game with German, Italian, French environment, copy enguke.fxt and rename it to geruke.fxt (German), itauke.fxt (Italien), freuke.fxt (France).
